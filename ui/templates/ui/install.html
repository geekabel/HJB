Installer l'application

{% icon "check" %}L'application est installée. Vous pouvez fermer cette page.

Avec l'application sur l'écran d'accueil, vous ouvrez la résidence d'un geste, comme une autre application. Sur iPhone, c'est aussi la seule façon de recevoir les notifications.

Votre navigateur peut l'installer tout de suite.

Sur iPhone ou iPad

  1. Ouvrez cette page dans Safari.
  2. Touchez « ⋯ » à côté de l'adresse, puis « Partager ». Sur un iPhone plus ancien, touchez le bouton Partager en bas de l'écran : le carré avec une flèche vers le haut.
  3. Choisissez « Sur l'écran d'accueil ». Si vous ne le voyez pas, faites défiler la liste vers le bas.
  4. Si une option propose d'ouvrir le site comme une app, laissez-la activée. Touchez ensuite « Ajouter ».
  5. Ouvrez désormais la résidence avec sa nouvelle icône, et non plus depuis Safari. La première fois, reconnectez-vous avec votre clé d'accès.

Les notifications demandent iOS 16.4 ou plus récent (Réglages, Général, Informations).

Sur Android

  1. Ouvrez cette page dans Chrome.
  2. Touchez le menu, les trois points en haut à droite.
  3. Choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  4. Confirmez avec « Installer ».
