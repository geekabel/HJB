Installer l'application

{% icon "check" %}L'application est installée. Vous pouvez fermer cette page.

Ajoutez la résidence à votre écran d'accueil. Sur iPhone, c'est obligatoire pour recevoir les notifications.

Sur iPhone ou iPad
  1. Ouvrez cette page dans Safari.
  2. Touchez « Partager » : le carré avec une flèche (ou « ⋯ », puis « Partager »).
  3. Touchez « Sur l'écran d'accueil », puis « Ajouter ».
  4. Ouvrez ensuite la résidence avec sa nouvelle icône.

iOS 16.4 au minimum.

Sur Android
  1. Ouvrez cette page dans Chrome.
  2. Touchez le menu « ⋮ » en haut à droite.
  3. Touchez « Installer l'application », puis « Installer ».
